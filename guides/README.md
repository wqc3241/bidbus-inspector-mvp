# Camera guides (Internal MVP)

One outline per guided shot, drawn on a 400 x 225 canvas (16:9, landscape camera). The app draws it over the live camera, centred in the photo area, and scales it with the zoom (0.5x 0.6, 1x 1, 2x 1.35).

- `svg/`: vector source. Lines are white at 85 %; the part to shoot is green (#4ade80, fill #22c55e at 20 %).
- `png/`: the same at 3x (1200 x 675), transparent background.
- tire_photo has one file per wheel (lf, lr, rr, rf); paint has one file per panel; the underbody shots have a gas version and an EV version (-ev).
